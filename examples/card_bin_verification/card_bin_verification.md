# Card BIN verification

This example checks the account balance and then looks up the card details of a BIN with the Bintable connector.

## Prerequisites

1. A Bintable API key from [bintable.com](https://bintable.com).

2. Create a `Config.toml` file in the example directory with the following values.

```toml
apiKey = "<API_KEY>"
bin = "<BIN>"
```

## Run the example

```bash
bal run
```
